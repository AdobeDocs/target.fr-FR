# Prévisualiser des expériences dans des activités [!UICONTROL Automated Personalization] dans le [!UICONTROL compositeur d’expérience visuelle] (VEC) {#preview-ap-experiences}

>[!BEGINSHADEBOX]

**Sur cette page :** Découvrez comment prévisualiser chaque expérience d’une activité **[!UICONTROL Automated Personalization]** dans le **[!UICONTROL compositeur d’expérience visuelle]** et comment exclure ou inclure des expériences.

>[!ENDSHADEBOX]

[!DNL Adobe Target] **[!UICONTROL Les activités Automated Personalization]** (AP) comparent plusieurs offres sur une page. Il est donc utile de prévisualiser la page avec chaque expérience. La prévisualisation montre comment les offres se combinent dans chaque expérience, afin que vous puissiez décider de la conserver ou de l’exclure.

1. Dans le **[!UICONTROL compositeur d’expérience visuelle]** (VEC), cliquez sur **[!UICONTROL Aperçu]**.

   ![Afficher l&#39;icône Aperçu](../assets/ap_preview_1.png)

1. Cliquez sur l’icône **[!UICONTROL Afficher les expériences]** (![Icône Afficher les expériences](/help/main/assets/icons/WebPages.svg)) pour afficher la liste de toutes les expériences dans le cadre de gauche.

   ![Icône Afficher les expériences](../assets/ap_preview_2.png)

1. Cliquez sur une expérience spécifique dans la liste pour l’afficher.

1. (Facultatif) Pour exclure ou inclure des expériences, cliquez sur l’icône **[!UICONTROL Gérer le contenu]** (![Icône Gérer le contenu](/help/main/assets/icons/Experience.svg)) pour afficher la boîte de dialogue **[!UICONTROL Gérer le contenu]**.

   ![Icône Afficher les expériences](../assets/ap_preview_3.png)

1. Vous pouvez choisir d’exclure une expérience qui affiche des variations en conflit ou une expérience qui n’est pas équilibrée esthétiquement. Effectuez ensuite l’une des opérations suivantes :

   * Pour exclure une expérience, cliquez sur l’icône **[!UICONTROL Autres actions]** (![Icône Autres actions](/help/main/assets/icons/MoreSmallList.svg)) en regard de l’expérience, puis cliquez sur **[!UICONTROL Exclure]**.
   * Pour exclure plusieurs expériences, cochez les cases correspondantes, puis cliquez sur **[!UICONTROL Exclure]**.
   * Pour inclure plusieurs expériences qui ont été exclues, cochez les cases correspondant aux expériences, puis cliquez sur **[!UICONTROL Inclure]**.
