# Prise en main des expériences et des offres {#experiences-overview}

>[!BEGINSHADEBOX]

**Sur cette page :** Découvrez ce qu’est une expérience dans [!DNL Adobe Target] et quels compositeurs d’expérience sont disponibles pour créer des expériences.

>[!ENDSHADEBOX]

Une expérience dans [!DNL Adobe Target] détermine le contenu qui s’affiche lorsqu’un visiteur répond aux critères d’audience d’une activité.

Une expérience peut être une offre, une image, un texte, un bouton, une vidéo, une combinaison de ces éléments sur une page, une page web entière ou un ensemble de pages qui forme peut-être un funnel d’achat ou une autre séquence logique de pages. Il peut également s’agir de la réponse d’un assistant vocal, d’un script de service clientèle ou même d’une saveur personnalisée provenant d’un distributeur de boissons. Les expériences sont testées ou personnalisées dans les activités [!DNL Target].

En règle générale, une activité contient plusieurs expériences. Par exemple, les visiteurs de Chambéry peuvent visualiser une offre de remise de 30 € sur les chaussures de ski, tandis que les visiteurs de Nice peuvent afficher une offre de remise sur les combinaisons de plongée. Une page contenant différentes offres spéciales pour les visiteurs récurrents peut également être testée. Chacune de ces offres est présentée dans une expérience distincte.

[!DNL Target] fournit les compositeurs d’expérience suivants :

| Type | Détails |
| --- | --- |
| [Compositeur d’expérience visuelle](/help/main/c-experiences/c-visual-experience-composer/visual-experience-composer.md) | Le compositeur d’expérience visuelle constitue l’une des principales fonctionnalités d’ [!DNL Adobe Target]. Il s’agit d’un éditeur qui permet aux marketeurs et aux concepteurs de créer et de modifier du contenu à l’aide d’une interface visuelle. De nombreux choix de conception peuvent être effectués sans modification directe du code. HTML et JavaScript peuvent également être modifiés à l’aide des options d’édition disponibles dans le compositeur. |
| [Compositeur d’expérience d’après les formulaires](/help/main/c-experiences/form-experience-composer.md) | Le compositeur d’expérience d’après les formulaires fournit une création d’expériences non visuelles. Il permet de diffuser [!DNL Target Standard] activités de tests A/B, de ciblage d’expérience, d’Automated Personalization et de [!DNL Recommendations] dans des e-mails, des kiosques et d’autres emplacements qui ne fonctionnent pas avec un compositeur d’expérience visuelle. |
| [Compositeur d’expérience visuelle (VEC) pour application monopage](/help/main/c-experiences/spa-visual-experience-composer.md) | Le compositeur d’expérience visuelle (VEC) pour applications d’une seule page (SPA) permet aux marketeurs de créer des tests et de personnaliser le contenu sans dépendances de développement continu. Il peut être utilisé pour créer des activités de test A/B et de ciblage d’expérience (XT) sur des frameworks populaires, tels que React et Angular. |
